# gromore_ads_kit 示例

这个示例用于验证插件能在 Android 和 iOS 工程中正确注册、解析原生 SDK 并完成构建。

真正请求广告前，请先按根目录 [`README.md`](../README.md) 配置：

- GroMore 后台的 Android/iOS App ID 和各广告位 ID；
- 用户隐私协议同意流程；
- Android 字节跳动 Maven 仓库和所选 ADN Adapter；
- iOS ATT、SKAdNetwork、隐私清单和所选 ADN；
- 只在 Debug 包中使用的官方预览测试工具。

占位 App ID 不会产生真实广告，请替换成你在 GroMore 后台创建的双端独立 App ID。
